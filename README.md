# WcBank

Projeto de landing page estática para o WcBank, um design de página inicial de serviço financeiro.

## Descrição

Este repositório contém um site estático em HTML e CSS que simula a apresentação de um banco digital. O layout inclui navegação, destaque principal, seções de serviços, cartão de crédito e rodapé.

## Estrutura do projeto

- `index.html` - página principal do site.
- `styles.css` - estilos do layout, cores e responsividade.
- `img/` - recursos gráficos usados na página.

## Tecnologias

- HTML5
- CSS3

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Ou hospede o projeto em um servidor estático para visualização local.

## Recursos

- Cabeçalho fixo com navegação.
- Seção hero com chamada para ação.
- Formulário simples de abertura de conta.
- Blocos de serviços e cartões de crédito.
- Rodapé com links de produtos e informações de contato.

## Observações

- Imagens estão na pasta `img/`.
- O projeto é uma interface estática, sem backend ou integração real.

## Contato

- Desenvolvido para demonstração de uma página de banco digital.
